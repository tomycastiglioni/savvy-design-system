Design, reinvented.

A visual audit of Savvy's current design system, pulled directly from the 2026 Website Redesign Figma file — colors, type, buttons, cards, badges, imagery and background texture as they actually ship today, not as they were documented before.

This replaces an earlier v1 of this reference that leaned on outdated brand guidelines — most notably a pill-shaped button system and a bright #175242 green that the current site no longer uses. Everything below was read out of the live redesign file, section by section.

Text — opacity on black/white, not a gray ramp

The redesign doesn't keep a separate set of gray hex values for copy hierarchy. Every text color is black (or white, in dark sections) at a fixed opacity — it inverts cleanly and there's one fewer set of tokens to maintain.

Spacing is organic

Not a strict 8pt grid

The v1 doc claimed a clean 8/16/32/64/120/160 scale. The actual file doesn't hold to one — gaps are tuned per component (8, 12, 14, 17, 21, 26, 30, 38, 41, 48, 60, 77, 94px all show up). What's consistent is the effect, not the numbers: generous, uneven, hand-tuned spacing rather than a rigid token ramp.

Buttons, not pills

5px radius, five variants

The v1 doc specified full pill buttons. The real system uses a tight 5px corner radius everywhere, and picks between five treatments depending on what sits behind the button.

Primary — flat gold, on cream/white
Nav / high-emphasis — flat black
Secondary — outline
On dark surfaces — white → ecru gradient, black text
Advisor-matching — terracotta gradient, white text

Stacked sheets

How sections meet

Full-bleed sections don't just butt up against each other — a dark section landing on a light one gets its own top corners rounded (20px), so it reads as a sheet laid over the page rather than a flat color change.

Photography direction

Candid, mixed with real product UI

Hero sections now run a mosaic of small square tiles that mix candid, golden-hour lifestyle photography with real screenshots of the Savvy product — a net-worth chart, an asset-allocation table — tinted with a soft color wash. It's less posed-portrait, more "here's actually what using this looks like."

Where a single portrait is needed — leadership team, "meet the advisor" — the crop goes circular; the advisor-directory grid keeps square crops instead.
